	# For scale, MEASURED: every one of AGOT's 158 culture definitions carries 5 or 6 traditions -- max 6,

	# CORRECTION, 27 Aug, and worth leaving in because it is the kind of mistake that reads as authoritative:
	# an earlier draft of this comment claimed "andal 17, freecities 12, first_man 11, ghiscari 10". Those
	# numbers came from `grep -c "traditions = {"` per FILE, which counts THE NUMBER OF CULTURES DEFINED IN

	# traditions. The figures were never real. Caught by an adversarial review pass.
	#
	# Three fits: DEFAULT_MAX_TRADITIONS = 5 (game/common/defines/00_defines.txt:1163), +1 per era joined,

	# assigned to nothing -- tradition_others2 alone carries knight_limit = 12, dread_baseline_add = 10,
	# max_loot_mult = 10, ai_war_chance = 1 and ai_war_cooldown = -0.95. This is wiring up existing work,
	# not new content, and it costs ZERO extra soldiers -- which is the whole point given Corvo's report
	# that his machine burns past 300k. Power density, not headcount.
	# They are assigned here rather than picked: each carries cost = { prestige = 10000 } and
	# ai_will_do = { value = 0 } precisely so no culture can ever take them through the UI.
	#
	# ── WHAT ELSE COMES WITH THEM, flagged rather than buried (adversarial review find). "Costs zero extra
	# soldiers" is true, but these are not purely military traditions. tradition_others2/3 also switch on a

	#     fort_level = 3                              -- their holdings get materially harder to besiege
	#     monthly_county_control_growth_factor = -1   -- control crawls on land they take
	#     development_growth = -1, tax_mult = -1      -- the dead do not build or bank
	#     supply_limit_mult = -0.5, county_opinion_add = 400
	#     monthly_prestige = -10, vassal_limit = 20, ai_boldness = 100, ai_war_chance = 1

	# use_prestige_to_buy_maa flag (zz_wight_government.txt) -- if the Night King ever looks starved of
	# men-at-arms rather than of men, that pairing is the first place to look.
