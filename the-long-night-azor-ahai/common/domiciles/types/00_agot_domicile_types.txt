# AGOT: The Long Night & Azor Ahai -- OVERRIDE OF $A/common/domiciles/types/00_agot_domicile_types.txt
#
# ══════════════════════════════════════════════════════════════════════════════════════════════════════════════
# ⚠ THIS FILE SHADOWS AN AGOT FILE. ONE CLAUSE IS CHANGED. DIFF IT ON EVERY AGOT UPDATE. ⚠
# ══════════════════════════════════════════════════════════════════════════════════════════════════════════════
#
# WHY IT EXISTS. AGOT built a complete landless Night's Watch ranger -- a government, a camp, and roughly 1,900
# lines of ranger events -- and locked every piece of it to ONE title, d_nw_landless_first_ranger. One First
# Ranger at a time. Thomas wanted the other seven seats at that table: "picture it, me and the boys playing as
# landless brothers of the Night's Watch."
#
# WHY THIS SHAPE AND NOT A NEW TYPE. My first cut defined ln_ranger_camp as a fresh domicile type, which is
# additive and carries no override hazard at all. It would also have been an EMPTY CAMP: all 59 camp buildings
# in $A/common/domiciles/buildings/00_agot_ranger_buildings.txt are gated on
# `allowed_domicile_types = { agot_ranger_camp }`, and eight other AGOT files reference that type key --
# customizable_localization, flavorization, game_concepts, scripted_rules, and their ranger contract triggers.
#
# The finding that settled it is AGOT's own trigger, $A/common/scripted_triggers/00_agot_first_ranger_laamp_triggers.txt:
#
#     agot_is_landless_nw_character = {
#         government_has_flag = government_is_nw
#         is_landed = no
#         is_ruler = yes
#         domicile ?= { is_domicile_type = agot_ranger_camp }
#     }
#
# It checks the CAMP TYPE, NOT THE TITLE. So a brother of ours who carries a government_is_nw government and an
# agot_ranger_camp slots into their entire ranger ecosystem for free -- every building, every piece of
# localization, every ranger contract. Keeping their type key buys all of that. A new type would have thrown it
# away and then needed a second override on the buildings file to get some of it back.
#
# So: ONE file shadowed, ONE clause widened, and their First Ranger's own path left byte-identical because the
# widening is an OR with their original line still in it.
#
# THE COST, STATED PLAINLY: every other line in this 852-line file is now frozen at the version it was copied
# from. If AGOT edits their pirate ship, or adds a domicile, or changes a camp building slot, this file
# silently reverts it and nothing logs a thing. Diff it against theirs on every update. It is a two-minute job
# and skipping it is how a mod quietly breaks its own dependency.
#
# TO REMOVE THIS FEATURE ENTIRELY: delete this file, common/landed_titles/zz_ln_ranger_titles.txt,
# common/governments/zz_ln_ranger_government.txt, and grep -r ln_ranger. Nothing else in the mod depends on it.
# ══════════════════════════════════════════════════════════════════════════════════════════════════════════════

		OR = {
