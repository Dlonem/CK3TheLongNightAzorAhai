# ── THE ONE ASSERTION ───────────────────────────────────────────────────────────────────────────────────────
# Root = a character who may be one of the dead.
#
# ONLY IF: he is one of them, he is a ruler, he is not already independent, and his DIRECT LIEGE IS LIVING.
# NEVER IF: his liege is also one of the dead -- an Other in the Night King's realm is where an Other belongs,
# and freeing him would shatter the dead's own hierarchy from the inside. That clause is the whole reason this
# is not simply "free every Other": in a chain of Other -> Other -> living king, only the OUTERMOST dead man
# matches, and freeing him carries his dead vassals out with him, which is the correct answer in one move.
ln_enforce_independence_effect = {
	if = {
		limit = {
			ln_is_one_of_them_trigger = yes
			is_ruler = yes
			is_independent_ruler = no
			exists = liege
			liege = { ln_is_one_of_them_trigger = no }
		}
		debug_log = "LN_TRACE INDEPENDENCE: one of the dead was serving a living liege and no longer is"
		debug_log_scopes = yes
		create_title_and_vassal_change = {
			type = independency
			save_scope_as = ln_independence_change
			add_claim_on_loss = no
		}
		becomes_independent = { change = scope:ln_independence_change }
		resolve_title_and_vassal_change = scope:ln_independence_change
	}
}

# ── THE SWEEP ───────────────────────────────────────────────────────────────────────────────────────────────
# Called once a year from ln_struggle_yearly_work_effect, behind that effect's own calendar stamp, so it runs
# exactly once a year however many characters reach the line.
#
# THE HOOKS ARE NOT ENOUGH ON THEIR OWN, and void's report is the proof: on_title_gain and on_vassal_gained
# catch a title CHANGING HANDS, but AGOT's megawar automation re-parents a title the dead already hold, which
# fires neither. A yearly pass is the only thing that closes a door nobody has enumerated yet. It is cheap --
# every_ruler once a year, and the limit rejects everyone living on its first clause. Same cost profile as
# ln_bastion_effects.txt, which walks every_ruler twice a year and says so.
ln_others_independence_sweep_effect = {
	every_ruler = {
		limit = {
			ln_is_one_of_them_trigger = yes
			is_independent_ruler = no
			exists = liege
			liege = { ln_is_one_of_them_trigger = no }
		}
		ln_enforce_independence_effect = yes
	}
}
