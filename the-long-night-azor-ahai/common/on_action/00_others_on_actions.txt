# AGOT: The Long Night & Azor Ahai -- THE OTHERS' CONVERSION HOOKS.
#
# 1.0.12: NOTHING IN THIS FILE DECLARES A VANILLA OR AGOT on_action ANY MORE. Every hook here is a
# uniquely-named sub-action; all five are registered under their real on_action in zz_ln_00_hooks.txt,
# per that file's standing rule.
#
# WHY ALL THREE OF THE REMAINING ONES HAD TO MOVE -- AND WHY THE OLD READING OF THIS WAS BACKWARDS.
# The engine settles a same-named on_action `effect` by PARSE ORDER INSIDE common/on_action/, not by
# mod load order. It says so out loud. From logs/error.log, 18 Aug run:
#
#   [E][jomini_onaction.cpp:161]: There is more than one 'effect' defined using most recent:
#       title_on_actions.txt   line 4312   (on_vassal_gained)
#       culture_on_actions.txt line 594    (on_county_auto_granted_to_local_culture)
#       culture_on_actions.txt line 426    (on_county_auto_granted_to_liege_culture)
#
# All three winners are AGOT's files. We are #4 in dlc_load.json and AGOT is #1, so load order was
# never what decided it. The rule that fits every collision observed in that log -- including AGOT's
# own internal ones (replace/agot_game_start.txt beating agot_game_start.txt; test_title_on_actions.txt
# beating agot_title_on_actions.txt) -- is: TOP-LEVEL FILES IN common/on_action/ ARE PARSED FIRST IN
# PATH ORDER, THEN SUBDIRECTORIES, AND THE LAST `effect` PARSED WINS. This file is called
# 00_others_on_actions.txt. It sorts ahead of every other file in the folder and loses every race it
# enters.
#
# SO THE REAL DEFECT WAS NEVER THAT WE WERE SUPPRESSING AGOT -- AGOT'S BLOCKS WERE ALWAYS THE LIVE
# ONES. It is that all three of ours had NEVER RUN, in any version, since the fork. The Others'
# mutate-on-grant mechanic was silently missing from vassalisation and from both county auto-grant
# routes. A hook that does not run produces silence, not a log line: this file's own siblings have
# been saying that since 1.0.8, and it was true here three more times.
#
# AND BOTH COUNTY BLOCKS WERE BROKEN ON THEIR OWN TERMS AS WELL. They read scope:recipient. The engine
# does not supply it. Vanilla culture_on_actions.txt and AGOT's copy of it BOTH create it inside their
# own effect -- `scope:landed_title.holder = { save_scope_as = recipient }` -- which is precisely the
# block ours displaced. Had we ever won the race, we would have read a scope that did not exist.
# The engine's own header on both hooks (vanilla culture_on_actions.txt:399) lists exactly three:
#       Root = The culture   |   scope:actor = The granter   |   scope:landed_title = The landed title
# So both now reach the new holder through scope:landed_title.holder, which is supplied, and neither
# depends any longer on AGOT's effect having run first.

# ── REMOVED 1.0.10a: on_title_granted WAS NOT A HOOK, AND HAD NEVER RUN ─────────────────────────────
# Inherited from the ancestor Long Night mod. It held a real mechanic -- when one of the dead granted a
# title, the recipient and his whole court mutated into Others -- and it had never fired once, in any
# version, because CK3 HAS NO on_title_granted. The engine's own list has on_title_gain, on_title_lost,
# on_title_gain_inheritance, on_title_gain_usurpation and the three on_county_auto_granted_to_* hooks
# (the two of those used further down this file are real and do work). An unknown on_action name is
# parsed, kept, and never called: no error, no warning, no behaviour. Found by the 1.0.10a wiring audit,
# which flags every sub-list in this mod that nothing references and that the engine does not fire.
#
# NOTHING IS LOST BY DELETING IT. ln_others_title_gain below already covers the same ground from the
# other side -- it fires on the real on_title_gain hook and mutates a character whose LIEGE is one of the
# dead, which is the same population this block was written for. The mechanic works; only this copy of it
# was dead. Left as a tombstone so nobody "restores" it.
# 1.0.10 -- WAS a bare `on_title_gain = { effect = {...} }`. This mod's own hooks file records the
# lesson (zz_long_night_plus_aftermath_effects.txt): a same-named on_action declared WITH AN EFFECT
# BLOCK in two places competes rather than merges, and the loser goes silent. Renamed to a sub-list
# and registered in zz_ln_00_hooks.txt beside the county-memory stamp, per the standing rule: a
# vanilla on_action is declared in the hooks file and nowhere else. Body untouched.
#
# 1.1.3 -- A REAL TRIGGER. on_title_gain fires for every title that changes hands anywhere in the world, and
# all four branches below need root or his liege to be one of the dead (the first needs other_trait, which is
# one of the identity markers). Refusing the living here, before the effect chain is built, is free; the body
# is unchanged and every branch still asks its own narrower question.
ln_others_title_gain = {
	trigger = {
		OR = {
			ln_is_one_of_them_trigger = yes
			liege ?= { ln_is_one_of_them_trigger = yes }
		}
	}
	effect = {
		if = {
			limit = { root = { has_trait = other_trait } }
			if = {
				limit = { NOT = { has_character_flag = others_heartbeat_active } }
				trigger_event = { id = others_heartbeat.1 }
			}
		}
		# 1.1.0 (A2.3): the liege test is ln_is_one_of_them_trigger, not other_trait. A WIGHT lord (wight_government,
		# wight_trait, no other_trait -- 1.0.6a's finding, see that trigger's header) handing out a title left the
		# recipient living and serving the dead. others_heartbeat.1 keeps its own other_trait trigger and refuses
		# a wight liege on its own; the mutate no longer depends on it.
		if = {
			limit = {
				exists = root.liege
				root.liege = { ln_is_one_of_them_trigger = yes }
			}
			root.liege = {
				save_scope_as = thegreatother
				if = {
					limit = { has_trait = other_trait  NOT = { has_character_flag = others_heartbeat_active } }
					trigger_event = { id = others_heartbeat.1 }
				}
			}
			root = { mutate_into_other_effect = yes every_courtier_or_guest = { mutate_into_other_effect = yes } }
		}

		# 1.1.1 (void) -- AND HE ANSWERS TO NOBODY LIVING. Outside the `if` above on purpose: a title gained by
		# one of the dead has to be checked whether or not the LIEGE is one of them, because the case that
		# broke was a title arriving with a LIVING liege attached to it. The effect's own limit does the
		# deciding; this is just the road in. See common/scripted_effects/zz_ln_independence_effects.txt.
		root = { ln_enforce_independence_effect = yes }

		# ══ 1.1.1b -- THE DEAD HAVE NO CONTROL PROBLEM. ═══════════════════════════════════════════════════
		# Thomas, 10 Sep, with a map full of hatched counties: "Let me know what you think about having
		# control at +100 for all lands owned by the night king that way he doesn't have to deal with
		# peasant revolts?"
		#
		# He had found the invasion stall. The 10 Sep -develop run, fifteen pulses of the invasion clock:
		# EIGHT of them logged "pulse ran, but the dead are already at war". The candidate clamp at
		# the_long_night.txt (the `is_at_war` trigger_if in the candidate limit) leaves only neighbours
		# under four counties eligible while he is at war, and those go down the fealty branch -- so a
		# standing peasant revolt is a standing war, and a standing war means the invasion never declares.
		# Same run: 44 faction_revolt_war, 44 peasant_faction, 30 populist_faction in eight minutes.
		#
		# WHY HIS COUNTIES REVOLT. Control never rises on land the dead hold. Before a county's culture
		# converts to frostborn it is an ordinary conquest -- foreign ruler, control left where the siege
		# left it. After it converts, tradition_others2 and tradition_others3 used to put a -2 flat and a
		# -100% factor on control growth (fixed in the same release, othertraditions.txt). Either way it
		# sat at the floor forever, and the floor is where peasant factions come from.
		#
		# WHY THIS COSTS HIM NOTHING. Control gates levies, taxes and development. His host is
		# create_maa_regiment scaling on sub-realm county COUNT (zz_ln_horde_effects.txt), not on levies;
		# tradition_others3 sets tax_mult = -1, so he collects nothing anyway. Control gave him nothing and
		# cost him everything -- it existed solely to generate revolts against him.
		#
		# WHY HERE. on_title_gain fires for every route a county can take into his hands -- war, grant,
		# inheritance, usurpation, the megawar automation -- so one hook covers every writer instead of a
		# clause at each of the fifteen grant sites. A modifier cannot set a control LEVEL, only its growth
		# and decline, which is why this is a snap and not a modifier. change_county_control is verified:
		# the mod uses it in five places and vanilla's peasant-war effects use it
		# (00_faction_effects.txt:1739, :2130). It clamps at the county's maximum.
		if = {
			limit = {
				root = { ln_is_one_of_them_trigger = yes }
				scope:title ?= { tier = tier_county }
			}
			scope:title = { change_county_control = 100 }
		}
	}
}


# 1.0.12 -- WAS a bare `on_vassal_gained = { effect = {...} }`, and had never fired. See the file header.
# Root = the character gaining the vassal, scope:vassal = the vassal being gained. Both are engine-supplied
# and both survive the sub-list indirection: AGOT ships the same pattern in
# agot_on_actions/agot_esr_on_actions.txt:207, where esr_on_vassal_gained is registered as a sub-list and
# reads scope:old_liege out of the parent hook. Body otherwise untouched.
# 1.1.0 (A2.3) -- THE FRENYA VECTOR. Thomas's 290 AC observer run: a living wildling chieftess, three titles,
# a thousand men, listed as the Night King's spymaster and his realm vassal at -100 opinion. She came in by war
# settlement under a WIGHT lord -- wight_government, wight_trait, no other_trait -- and this hook asked for
# other_trait, so she stayed alive and stayed his. ln_is_one_of_them_trigger is the identity test everywhere
# else in the mod; it is the test here now too. The yearly self-heal on the story pulse (the_long_night.txt)
# catches anyone who got in by a road with no hook at all.
ln_others_vassal_gained = {
	effect = {
		if = {
			limit = {
				root = { ln_is_one_of_them_trigger = yes }
			}
			root = { save_scope_as = thegreatother }
			scope:vassal = {
				mutate_into_other_effect = yes
				every_courtier_or_guest = {
					mutate_into_other_effect = yes
				}
			}

			# 1.1.1 (void) -- gaining a vassal is one of the shapes a war settlement takes, and a settlement
			# that hands one of the dead a vassal can just as easily have handed him a LIEGE. Checked on root,
			# not on the new vassal: a vassal of one of the dead is exactly where he belongs and the effect's
			# own limit refuses to touch him.
			root = { ln_enforce_independence_effect = yes }
		}
	}
}

# ── 1.1.2: THE DEAD DO NOT ACQUIRE A LIEGE, AND NOW WE FIND OUT ON THE DAY ───────────────────────────────
# Registered on vanilla's on_vassal_change from zz_ln_00_hooks.txt; see the long note there for why this hook
# and not on_vassal_gained. Root = the character whose liege changed. The hook also fires when a ruler gains
# independence, which is why the body does no work of its own: the effect it calls carries its own limit. A
# newly-independent Other does match it now (1.1.3: the dead serve the Night King, so he is sworn to him),
# and the one-day ln_being_freed flag stops the change it starts from re-entering.
#
# WHY THE ONE CALL DOES BOTH THINGS. ln_enforce_independence_effect puts him back where he belongs AND ends,
# unconditionally, with the strip that takes AGOT's pre-war-liege marker off him so the megawar rebuild stops
# selecting him at all. The strip is the one that prevents the damage -- see zz_ln_independence_effects.txt --
# and it runs whether or not the freeing part applied, which matters here because the marker is set on the
# way IN to a vassalage, so a ruler who has just been handed a liege is precisely the one carrying it.
# (1.1.2 called the strip a second time after the effect; that was the same strip twice.)
#
# 1.1.3 -- A REAL TRIGGER, NOT AN `if` INSIDE THE EFFECT. This fires on every liege change in the world, and
# the living never need to enter it. A trigger block is refused before the effect chain is even built; the
# old shape built the chain and then asked. Same result, and it is the shape the engine offers for this.
# (Thomas's 13 Sep log also showed this hook re-entering ln_enforce_independence_effect fifty deep on dead
# barons; that half is fixed in the effect itself -- see zz_ln_independence_effects.txt.)
ln_others_vassal_change = {
	trigger = {
		ln_is_one_of_them_trigger = yes
	}
	effect = {
		debug_log = "LN_TRACE INDEPENDENCE: one of the dead changed liege - checking him"
		ln_enforce_independence_effect = yes
	}
}

# ── 1.1.3: THE DEAD MARCH ALONE ─────────────────────────────────────────────────────────────────────────
# Discord thread, 19 Sep, with screenshots: living rulers on the Night King's side of an invasion war --
# "+ Allies (2)", a Targaryen-looking king, a queen with a crow sigil, an 11-month war at -27% that had
# picked up a paid ally. Our alliance ban holds (zz_ln_alliance_rules.txt and the yearly sweep); alliances
# were never the road. AGOT and vanilla have at least six other doors, and not one of them asks who leads
# the war: join_war_interaction (any landless adventurer, auto-accepted), contract_assistance (paid help,
# likelier when the recipient is losing), hire_laamp_mercenaries (he hires a company), laamp_war_change_sides
# (a hired company defects to him), a living TRIBUTARY (wight_government is tribal, tribal authority grants
# can_have_tributaries, and tributaries may join his wars), and AGOT's mega-war rebels on pre-1.1.2 saves.
# AGOT runs its sellsword and exile companies as landless adventurers -- d_laamp_targaryen_exiles carries
# the dragon -- which is what the screenshot looks like. Full working in claude/EVIDENCE-26sep-A-wars.md.
#
# ONE CHOKE POINT. Every one of those roads ends in the engine's own on_join_war_as_secondary (root = the
# joiner, scope:war = the war; vanilla war_on_actions.txt:14-18). Registered from zz_ln_00_hooks.txt. A
# living man who has just joined the side the dead LEAD is removed on the spot. The living joining the War
# for the Dawn, or defending against an invasion, are untouched: there the side's leader is living. And one
# of the dead joining a living-led side is left alone here -- that is a different question, recorded, not
# decided. remove_participant in war scope is vanilla's (06_ep3_laamp_interactions.txt:7390) and AGOT's
# (agot_war_on_actions.txt:357). Removing inside this callback has no precedent found; if the boot shows a
# log line or a stuck war entry, move the removal to a one-day hidden event and keep this as the detector.
# The 30-day/yearly sweep in zz_ln_service_effects.txt is the belt for wars already running and for any
# scripted add_attacker this hook turns out not to see.
ln_the_dead_march_alone = {
	trigger = {
		ln_is_one_of_them_trigger = no
		exists = scope:war
	}
	effect = {
		scope:war = {
			if = {
				limit = {
					is_attacker = root
					primary_attacker = { ln_is_one_of_them_trigger = yes }
				}
				debug_log = "LN_TRACE ALLIES: a living ruler joined the dead's side of a war - removed"
				debug_log_scopes = yes
				remove_participant = root
			}
			else_if = {
				limit = {
					is_defender = root
					primary_defender = { ln_is_one_of_them_trigger = yes }
				}
				debug_log = "LN_TRACE ALLIES: a living ruler joined the dead's side of a war - removed"
				debug_log_scopes = yes
				remove_participant = root
			}
		}
	}
}
