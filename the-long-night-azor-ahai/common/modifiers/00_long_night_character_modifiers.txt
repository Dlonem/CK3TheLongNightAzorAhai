
# ── 1.0.16: THE DIFFICULTY SLIDER STOPS BEING A HEADCOUNT SLIDER ────────────────────────────────────
# WHAT WAS WRONG. Each tier was ONE field, levy_size, and nothing else. Reported independently from two
# directions:
#   Zobertus (Discord): "the Insane strength only adds a levy modifier make them way too easy to deal with
#     (as levies are useless in battle)." Correct, and provable: LEVY_TOUGHNESS 10, LEVY_ATTACK 10,
#     LEVY_SIEGE 0 (game/common/defines/00_defines.txt:588-590) against other_maa at 38 / 75 / siege 0.9.
#     No tier of this rule could make the dead hit harder, survive longer, or take a castle.
#   KhanSaru (Steam): "I'm king of the seven kingdoms with dragons, and I am not doing anything about the
#     Others... the Others are being beaten by the Wildlings."
#
# THE NUMBERS ARE NOT A "UNITS FIX". levy_size is a fraction in CK3 and 15/25/50/75 read as +1500%/+2500%/
# +5000%/+7500%, which looks like somebody meant 0.15. But those values have shipped for many versions and
# produce playable games, so they were functioning as a deliberate headcount dial -- the ONLY dial. Blindly
# "correcting" them to 0.15-0.75 would have cut the horde by ~100x and deleted the Army of the Dead. This is
# a considered retune, not a typo repair.
#
# WHAT IT IS TUNED AGAINST. Corvo (Discord): "had to play on 'weak' night difficulty because my PC BURNS if
# they get past 300k." The old multipliers were weak 18x, standard 28x, strong 53x, insane 78x -- so INSANE
# put roughly 1.3 MILLION men on the map from the same map position where weak put 300,000, and choosing
# framerate and choosing easy were the same choice. That is the bug behind his report.
# Insane is now ~14x, i.e. it lands near the 300k Corvo named -- today's WEAK headcount -- while hitting far
# harder than today's insane. The horde fantasy is intact; the waste is gone.
#
# AND THE MEN WE CUT WERE NOT FIGHTING ANYWAY. NCombat.BASE_WIDTH_RATIO = 1 (00_defines.txt:597): combat
# width is set by the size of the DEFENDER. In this mod's own live record, 429,171 attackers met 32,710
# defenders -- roughly 92% of the dead stood in reserve, costing simulation and buying nothing.
#
# WHERE THE THREAT WENT INSTEAD. advantage is CK3's own difficulty knob and costs zero soldiers:
# ADVANTAGE_DAMAGE_SCALING_FACTOR = 5 (00_defines.txt:596), so every point is +5% damage -- insane's 16 is
# +80%. Shape mirrors zz_ln_wave_modifiers.txt, which already had it right.
# NOTE siege deliberately stays out of these tiers: ln_the_dead_do_not_tire_modifier already carries
# siege_phase_time and levy_siege, and stacking two sources of it is not reasonable-able from the files.
# 1.1.0 (§9.3 dial 2): re-verified, the decision HOLDS. zz_ln_siege_modifiers.txt:54-59 is still the one
# source (levy_siege 0.004, siege_morale_loss 0.5, siege_phase_time -0.25) and its own header explains why
# a second source per tier is wrong. Revisit only off boot item 16's measurement, never from the armchair.

# ── 1 Sep 2026: THE ADVANTAGE LADDER, RESET ON THOMAS'S NUMBERS ────────────────────────────────────────
# Live Long Night, Strong, 290 AC: the Night King fielded 5.2M strength against Thomas's 1.6M and lost every
# engagement decisively. "I still feel like we need to make the Night King a little bit stronger."
#
# WHY MASS WAS NOT THE ANSWER *AT THE TIME*. When this was written, NArmy.REGIMENT_DEFAULT_MAX_SIZE = 3
# (game/common/defines/00_defines.txt:641) clamped every create_maa_regiment and ln_wight_horde set no `max`,
# so the horde's old 4/6/8 conquest tiers were inert. ⚠ NO LONGER TRUE (1.1.0b, 1 Sep): ln_wight_horde now
# carries max = 20 and the horde is a milestone ladder (zz_ln_horde_values.txt: 20k / 50k / 100k / 200k /
# 250k on Standard, x0.75 / x1.25 / x1.5 by rule, hard cap 500,000 -- Thomas's King's Landing number). Mass
# and advantage now BOTH scale. Advantage stays the cheap knob: ADVANTAGE_DAMAGE_SCALING_FACTOR = 5, invisible
# in the save, costs not one extra soldier.
#
# THOMAS'S CALL, verbatim: "15 across the board, 20 on strong and insane, and 15 for normal, and 10 for weak."
#     weak      3 -> 10
#     standard  6 -> 15
#     strong   12 -> 20
#     insane   16 -> 20
#
# ⚠ THIS COLLAPSES THE STRONG/INSANE GAP ON ADVANTAGE, on purpose, because that is what he asked for. Insane
# keeps its separation on the three terms Strong does not have at all: toughness 0.35 vs 0.20, damage 0.30 vs
# 0.15, and knight_effectiveness_mult 0.25 vs none. If the two tiers ever start to FEEL the same in a run,
# that is the line to move, not this one.
#
# THE STACK, so nobody has to reconstruct it again. These are additive with two other sources on the same
# character: night_king_command_modifier (advantage 12, standing) and ln_apply_wave_escalation_effect
# (advantage 3/6/10 at waves 2/4/6). Real ceilings after this change:
#     weak,     wave 1   10 + 12       = 22
#     standard, wave 1   15 + 12       = 27
#     strong,   wave 1   20 + 12       = 32
#     insane,   wave 6+  20 + 12 + 10  = 42
# The old insane ceiling was 38, so the top of the game moves +4 and the BOTTOM moves +7 -- Weak is the tier
# that changes most here, which is intended: it was 3.

others_weak_modifier = {
	levy_size = 3
	advantage = 10
}


others_standard_modifier = {
	levy_size = 6
	advantage = 15
	army_toughness_mult = 0.10

	# The agreed target (31 Aug 2026): on Strong, +20 years after the invasion, THE NORTH HAS FALLEN and

# The Long Night+: with fewer Others promoted (conquered now rise as weak wights), the Night King's host
# bleeds its elite faster than it can replace them. This standing command bonus keeps the dead a credible
# threat — a harder-hitting, more durable horde led by a dread general who fields more of his Others as knights.
night_king_command_modifier = {
	# ── 1.1.0, 1 Sep: HE CANNOT RUN OUT OF THE ONE CURRENCY HE NEEDS. ──────────────────────────────────
	# Workshop report, Enigmatic Clown, 28 Aug: "I found that the Night King will stop invading if he
	# doesn't have enough prestige. Could you give him some more?"
	#
	# WHAT WAS CHECKED. other_cb's cost block is empty (00_long_night_cbs.txt:281), so the invasion CB
	# itself charges nothing, and base CK3 has no define that gates a war declaration on prestige. He also
	# already receives add_prestige = 5000 at spawn. So there is no single line to point at -- but there IS
	# a drain: every white peace on the invasion CB costs him 500 (00_long_night_cbs.txt:92), the AI weighs
	# prestige when it decides to declare at all, and a ruler sitting at a negative prestige LEVEL carries
	# real penalties. A one-off grant at spawn cannot survive a long war of white peaces.
	#
	# So he gets an income instead of a lump sum. 120 a year: a white peace is recovered in four, he can
	# never bottom out, and it costs zero soldiers -- the governing constraint of this whole file. Prestige
	# is meaningless to the dead as a story; it is only ever a currency the engine makes him spend.
	monthly_prestige = 10

	advantage = 12
	army_damage_mult = 0.20
	army_toughness_mult = 0.20
	knight_effectiveness_mult = 0.50
	knight_limit = 6

	# ── 1.0.16 ADDITIONS. Both cost zero soldiers, which is the governing constraint this release. ──────
	# DOMAIN LIMIT. He takes counties personally -- other_cb's on_victory hands occupied land straight to
	# him via ln_contiguous_conquest_effect -- and then bleeds control and levies for being over the limit
	# (ABOVE_LIMIT_LEVY_PENALTY = 0.2 per holding, game/common/defines/00_defines.txt:1062). So the more of
	# the North he took, the less each new county was worth to him. He should be able to HOLD what he takes.
	# This also compounds correctly with the strength retune above, because his host size keys off county
	# count rather than off the levy multiplier now.
	domain_limit = 10

	# DREAD, PINNED AT THE CAP. MAX_DREAD = 100 and BASE_DREAD = 0 (00_defines.txt:120-121), and dread
	# drifts toward a character's baseline at DREAD_MONTHLY_CHANGE = 0.5/month, so a baseline add of 100
	# holds him at maximum permanently instead of letting him decay toward ordinary. Thomas: "there needs
	# to be like a make sure the Night King has like 100% dread. It wouldn't be reflected by percent, by
	# the way" -- correct, it is a 0-100 scalar, and 100 is the ceiling.
	# This is also the honest version of what people are asking for when they suggest giving him the
	# `conqueror` trait: that trait's payload is title-creation cost, legitimacy, monthly income and herd
	# capacity -- almost none of which he uses -- and it carries ai_war_chance = -100 where every other
	# value in the traits file sits between -0.9 and +1.0. Dread, advantage and domain do the work without
	# the baggage.
	dread_baseline_add = 100
}
# ── BEING NAMED, AS A MODIFIER RATHER THAN AS FIVE THOUSAND OPINION ROWS ──────────────────────────────
# 1.0.10b. These replace the every_ruler + add_opinion sweep in ln_the_world_forms_a_view_effect --
# see the comment there for the full account of what was traded away and why.
#

# faith sees the bonus without anyone having written a row for him. clergy_opinion is stacked on top of

	different_faith_opinion = -8
}
