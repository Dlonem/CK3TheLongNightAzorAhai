# ── BEING NAMED, AS A MODIFIER RATHER THAN AS FIVE THOUSAND OPINION ROWS ──────────────────────────────
# 1.0.10b. These replace the every_ruler + add_opinion sweep in ln_the_world_forms_a_view_effect --
# see the comment there for the full account of what was traded away and why.
#
# Reach is unchanged: same_faith_opinion and different_faith_opinion are resolved by the engine against
# whoever is currently looking at this character, so a stranger on the far side of Essos who shares the
# faith sees the bonus without anyone having written a row for him. clergy_opinion is stacked on top of
# same_faith_opinion so priests specifically like a named claimant more than the ordinary faithful do,
# which is the one piece of the old zealot/red-priest filter worth keeping.
#
# Numbers carried over from ln_named_opinion_up_value / _down_value so the felt result is the same:
#   Favored  +10 same faith (+10 more from clergy) / -8 different faith
#   Chosen   +25 same faith (+15 more from clergy) / -18 different faith
# Applied with years = 20, which is what the old opinion modifiers carried.
ln_named_favored_modifier = {
	icon = piety_mixed
	same_faith_opinion = 10
	clergy_opinion = 10
	different_faith_opinion = -8
}

ln_named_chosen_modifier = {
	icon = piety_mixed
	same_faith_opinion = 25
	clergy_opinion = 15
	different_faith_opinion = -18
}
