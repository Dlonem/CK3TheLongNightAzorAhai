# AGOT: The Long Night & Azor Ahai -- who the fire is already looking at.
#
# THE PROBLEM THESE SOLVE. The blessing's scoring model rated a man by his TITLE. That is right for Stannis
# and wrong for everyone else who matters: Daenerys is a landless adventurer, Jon Snow is a bastard with no
# seat, Beric Dondarrion is a knight with a warrant out for him, and Ser Duncan the Tall is lowborn on
# purpose (`set_to_lowborn = yes`, history/characters/00_agot_char_dragonstone_ancestors.txt:16056).
# Station cannot be the only axis of importance or the Lord of Light never looks at any of them.
#
# EVERY SIGNAL BELOW IS AGOT'S OR VANILLA'S, VERIFIED, NOT INVENTED. In particular there is NO
# has_valyrian_steel_sword trigger anywhere in AGOT -- it has to be built, and it has to check the type,
# because the valyrian_steel variable is set on ARMOUR too (00_agot_artifact_armor_effects.txt:231).
# A man in a good breastplate is not Azor Ahai.

# Does he own Valyrian steel with an edge on it?
# agot_is_valyrian_steel_artifact -- 00_agot_artifact_triggers.txt:44, body is `has_variable = valyrian_steel`.
# artifact_type = sword -- VANILLA, common/artifacts/types/00_types.txt:163.
# Ownership rather than equipped: the sword finding the man is the omen. Whether he has it strapped on
# this afternoon is not. This is the same list AGOT's own reforge_valyrian_steel_decision reads.
ln_carries_valyrian_steel_trigger = {
	any_character_artifact = {
		agot_is_valyrian_steel_artifact = yes
		artifact_type = sword
	}
}

# THE CANON CLAUSE, and it is the best thing in this file. AGOT flags its book characters with
# canon_status_canon -- tested at 00_agot_character_triggers.txt:156. It is NOT a static history stamp:
# the canon-children system adds it AT BIRTH (00_agot_canon_children_character_birth_effects.txt:4), so an
# Aegon born to Viserys and Alicent in year 40 of a campaign carries it from the day he is born, with the
# same stable historical ID he would have had at a later bookmark.
#
# So this reads "the story has a use for this person" WITHOUT hardcoding a single name, and it keeps
# working for people who did not exist when the game started. Thomas: "a character might not be created at
# game start, but will identifiably get created later."
ln_bears_a_destiny_trigger = {
	OR = {
		has_character_flag = canon_status_canon
		has_character_flag = canon_status_semicanon
		ln_carries_lightbringer_trigger = yes
		ln_carries_valyrian_steel_trigger = yes
		agot_is_dragonblood_character = yes
		agot_has_dragonblood_heritage = yes
		has_trait = dragon_dreams
		has_trait = greensight
		has_trait = azor_ahai_reborn
		has_trait = chosen_by_rhllor
		has_trait = favored_by_rhllor
	}
}

# THE WEAPON, NOT THE SAINT. Thomas: "this really terrible person might be exactly what the realm needs
# right now, whether nobody knows it at the time or not."
#
# R'hllor does not pick the good. He picks the NECESSARY -- Melisandre burns people. In the Long Night
# itself the priesthood stops auditing character and starts looking for something that kills. A cruel,
# capable, driven man in that hour is exactly what a fire god reaches for, and nobody alive understands why.
# Gated on the phase deliberately: this is not how the faith behaves in the Long Summer.
ln_is_the_weapon_trigger = {
	struggle:ln_long_night_struggle ?= { is_struggle_phase = ln_phase_the_long_night }
	prowess >= 14
	OR = { has_trait = ambitious  has_trait = brave  has_trait = vengeful }
	OR = { has_trait = sadistic  has_trait = callous  has_trait = arrogant  has_trait = vengeful }
}

# ══ 1.0.15b -- WHAT CAN ACTUALLY END HIM ════════════════════════════════════════════════════════════════════
# Thomas, 24 Aug: "it should arguably be impossible for the Night King to die unless the character fighting
# them has Dragonglass, aka Obsidian, or a Valyrian steel sword, or happens to occur from a Dragon."
#
# That is the book's rule and it is the one thing the mod had never enforced: any lord with a good sword
# could end the Long Night if the roll went his way. Now the three answers are the ONLY answers, and each
# clause below reads a marker this mod already sets somewhere else -- nothing here is new state.
#
#   DRAGONGLASS -- the two Prepare decisions' modifiers (zz_ln_preparation_effects.txt:41, :85), the stores,
#                  and the mined-it flag. The children of the forest's answer, and the cheapest to get.
#   VALYRIAN STEEL -- a sword artifact by AGOT's own agot_is_valyrian_steel_artifact, the prophecy layer's
#                  deed, the armed modifier, and both consecration routes (Lightbringer is Valyrian steel
#                  that has been paid for twice; Dawn is not Valyrian steel at all, but it is the Sword of
#                  the Morning and if it cannot end him nothing can).
#   DRAGONFIRE  -- a living dragon under you that is not one of theirs.
#
# WHERE IT IS ENFORCED: the open-field duel's winning branch (ln_dawn.2), the cornering and the execution
# (ln_dawn.11), the failsafe (ln_dawn.12), and -- the one that closes the back door -- the death catalyst
# itself, so a Night King killed by ordinary steel in some anonymous battle is CAST DOWN AND NOT DESTROYED:
# the dark crowns another and the Long Night goes on. See zz_ln_catalyst_effects.txt.
ln_bears_the_bane_trigger = {
	OR = {
		has_character_modifier = ln_dragonglass_armed_modifier
		has_character_modifier = ln_dragonglass_stores_modifier
		# 1.0.15c REVIEW FIND -- AND THE ONE THAT NEARLY BROKE THE WHOLE RULE. The lord gets
		# ln_dragonglass_armed_modifier; every KNIGHT and courtier in his hall gets
		# ln_dragonglass_knight_modifier instead (zz_ln_preparation_effects.txt:98-117), whose own
		# localisation reads "it kills what steel will not touch". Leaving it out meant the candidate pool
		# the cornering was built for -- "Jon Snow sworn to somebody else's banner is exactly the man this
		# exists for" -- was baneless to a man, and an armed knight who killed him in the field cast him
		# down instead of destroying him.
		has_character_modifier = ln_dragonglass_knight_modifier
		has_character_flag = ln_mined_the_glass

		ln_carries_valyrian_steel_trigger = yes
		ln_has_deed_valyrian_steel_trigger = yes
		has_character_modifier = ln_valyrian_armed_modifier
		has_character_flag = ln_forged_lightbringer
		has_character_flag = ln_the_star_paid_for_it

		# ⚠ 1 Sep -- THE WALL CASCADE, approved by Thomas: "I think you should do the dragon bane cascade."
		# This clause used to be ln_rides_a_living_dragon_trigger, which asks whether the man HAS a dragon.
		# Beyond the Wall that is the wrong question: she would not cross, so the one thing he brought that
		# could end the Night King is a hundred leagues south of the field, and the card was still offering him
		# the winning swing. ln_dragon_is_over_the_field_trigger asks whether she is actually HERE, and it opens
		# again the moment the dead hold a piece of the Wall and the ward fails.
		#
		# WHAT THIS COSTS A TARGARYEN, stated plainly because it is a real loss: a rider whose ONLY bane is his
		# dragon can no longer kill the Night King north of an intact Wall. He reads ln_dawn.2.desc.dragon_refused,
		# which says exactly that, and he is offered option d -- go out there anyway. He fixes it by bringing
		# obsidian or Valyrian steel, by forcing the fight south of the Wall, or by waiting for the Wall to
		# break. All three are the story this mod exists to tell, and none of them was reachable before.
		ln_dragon_is_over_the_field_trigger = yes
	}
}

# ══════════════════════════════════════════════════════════════════════════════════════════════════════════
# THE BANE IS NOT ONE THING. 1.0.16 -- ln_bears_the_bane_trigger above is a flat OR: obsidian counts exactly
# as much as Valyrian steel, which counts exactly as much as a dragon. Two reporters found the consequence
# from opposite ends on the same day:
#   KhanSaru (Steam): "I'm king of the seven kingdoms with dragons, and I am not doing anything about the
#     Others."
#   Corvo (Discord): "if dragons even the insane difficulty is easy" -- and, by accident, the control
#     experiment for it: his dragon eggs were destroyed, he fought the whole Long Night on troops alone, and
#     it became HARD on the WEAK setting. Same player, same mod, one variable removed.
#
# Thomas: "Valyrian steel should beat dragon glass nine times out of ten... Dragon glass is definitely half
# as effective as Valyrian steel, cuz it's harder to get that situation."
#
# ── WHY THIS IS A TRIGGER AND NOT A REWRITE OF ln_bears_the_bane_trigger ──────────────────────────────────
# That trigger has eleven call sites and one job: "is he armed at all". It still answers that, unchanged, and
# it still governs whether the Night King can be killed at all. What was missing was the SECOND question --
# armed with WHAT -- and the honest place for it is beside the first, not inside it.
#
# ── AND WHY THIS IS A PENALTY ON GLASS RATHER THAN A BONUS ON STEEL ───────────────────────────────────────
# The duel in ln_dawn.2.a already rewards the top of the ladder: -25 to the losing branch for Lightbringer,
# -20 for the bleeding star, -15 for a Valyrian deed. Dragonglass alone gets nothing from that layer, so
# adding a fresh tier bonus on top of it would double-count the same three flags. The gap Thomas described
# is opened from the bottom instead: a man whose ONLY answer is obsidian is meaningfully likelier to fall.
ln_carries_only_dragonglass_trigger = {
	# He is armed...
	ln_bears_the_bane_trigger = yes
	# ...and with nothing better than glass.
	NOR = {
		ln_carries_valyrian_steel_trigger = yes
		ln_has_deed_valyrian_steel_trigger = yes
		has_character_modifier = ln_valyrian_armed_modifier
		has_character_flag = ln_forged_lightbringer
		has_character_flag = ln_the_star_paid_for_it
		# Same cascade as ln_bears_the_bane_trigger: a dragon that could not cross the Wall is not a better
		# answer than obsidian on a field she is not over, so her rider takes the glass-only penalty there.
		ln_dragon_is_over_the_field_trigger = yes
	}
}

# Root = the Night King, at the moment of death. Did the hand that did it carry one of the three?
# A DRAGON as the killer is dragonfire by definition -- the engine names the animal as scope:killer when a
# dragon burns somebody, which the reveal already knows about and redirects to the rider.
ln_slain_by_a_bane_trigger = {
	exists = scope:killer
	scope:killer = {
		OR = {
			has_trait = dragon
			ln_bears_the_bane_trigger = yes
		}
	}
}
