# AGOT: The Long Night & Azor Ahai -- is there a castle standing empty?
#
# WHY THIS FILE EXISTS AT ALL, AND WHY THE FIRST VERSION WAS WRONG.
#
# Thomas took the black in a live 111 AC run and got this: "I've got the Fief of the Night Fort. However, I'm
# not considered a member of the Night's Watch... I do not have a liege. My liege should be the Lord Commander.
# Whoever coded this seems to have forgotten every other thing that would happen in regard to joining the
# Night's Watch when they make that decision."
#
# He was right on every count, and the cause was that I had hand-rolled a title grant instead of looking for
# what AGOT already had. The engine log said `change_government effect [ Trying to set illegal government ]`
# and the reason is sitting in AGOT's own government file:
#
#     nights_watch_government = {
#         can_get_government = {
#             OR = { has_title = title:k_the_wall   any_liege_or_above = { has_title = title:k_the_wall } }
#             OR = { has_trait = nightswatch  has_trait = nightswatch_temp  has_trait = nightswatch_historical }
#         }
#     }
#
# BOTH clauses. A man who is handed a Wall county out of nowhere has neither: no nightswatch trait, and no
# liege, because a title granted by script does not make you anybody's vassal on its own. So the government
# change was refused, and what he was left with was an independent feudal count sitting on the Wall.
#
# WHAT AGOT ALREADY HAD -- and this is the part I should have found first.
#
#   common/court_positions/types/01_agot_nights_watch_positions.txt
#
# Eighteen court positions, one per castle on the Wall: b_the_nightfort_keeper, b_deep_lake_keeper,
# b_greyguard_keeper, and so on. Every single one of them ends with exactly the flow that was missing:
#
#     on_court_position_received = {
#         create_title_and_vassal_change = { type = granted  save_scope_as = title_change  add_claim_on_loss = no }
#         title:c_the_nightfort = { change_title_holder_include_vassals = { holder = scope:employee_saved  change = scope:title_change } }
#         resolve_title_and_vassal_change = scope:title_change
#         scope:employee = { change_government = nights_watch_government }
#     }
#
# The employee is a courtier of the Lord Commander, so the grant makes him the Lord Commander's VASSAL, which
# is what satisfies `any_liege_or_above = { has_title = title:k_the_wall }`, which is what lets the government
# change succeed. AGOT built the whole road. I built a second one next to it that went off a cliff.
#
# So this mod no longer grants anything itself. It puts a man through AGOT's own joining effect
# (agot_add_to_nightswatch_effect -- which unbonds his dragon, ends his betrothal, hands on his house, strips
# his claims and gives him the nightswatch trait), moves him into the Lord Commander's court, and then appoints
# him to one of AGOT's keeperships. Everything after that is their code.
#
# THOMAS: "what if my homies want to also join the Night's Watch with me?" -- Eighteen keeperships, one man
# each, handed out in a fixed order and released back to the Lord Commander by AGOT's own
# on_court_position_revoked when a man deserts or dies. Eighteen players can take the black in one game, each
# with his own castle, without a line of rotation logic in this mod.
#
# THOMAS: "Isn't there like a Restore the Nightfort decision or something? I wanna make sure that we're
# exhausting all interwoven possibilities before creating a new backdoor." -- This is that check, and the
# answer turned out to be yes. There was no new backdoor to build; there was a door I had walked past.

# WHICH CHARACTER DOES THE APPOINTING, AND WHY IT IS ALWAYS THE LORD COMMANDER HERE.
#
# AGOT's keeperships form a hierarchy. The employer for each one is the holder of the county the castle sits
# in, so once a player takes the Nightfort HE becomes the employer for Stonedoor and Hoarfrost Hill, and the
# Lord Commander is no longer involved. Their own reconciler in
# common/on_action/agot_on_actions/agot_wall_on_actions.txt appoints across five different employers.
#
# This decision does not try to model that. It offers a keepership ONLY when the Lord Commander still holds
# the title that keepership grants, which makes all three engine requirements true at once:
#
#   * the employer holds the title, so on_court_position_received grants it out of his own demesne instead of
#     taking it off somebody else;
#   * the recruit is his courtier, which appoint_court_position requires outright ("If employee doesn't have
#     employer as liege" is a documented error case);
#   * the recruit becomes HIS vassal, which is what satisfies can_get_government.
#
# The list shrinks on its own as the Wall fills up. A player who takes the Nightfort takes its baronies with
# it via change_title_holder_include_vassals, so Stonedoor and Hoarfrost Hill drop off this list at the same
# moment -- and if he wants them manned, he appoints his own keepers through AGOT's normal court interface,
# which is exactly the Lord Commander fantasy Thomas described: "essentially he should be the king of the
# Wall, and will command those taking care of those things."

# Is a given keepership open? The Lord Commander must still hold the title it grants -- otherwise
# appointing to it would take that castle off whoever holds it now -- and nobody may be sitting in it.
# any_court_position_holder is the engine's own list (vanilla reads it with `type = X` in
# common/court_positions/types/00_camp_officers.txt among others); max_available_positions = 1 on every
# keeper means one holder is the whole set.
ln_keepership_is_free_trigger = {
	exists = title:k_the_wall.holder
	title:k_the_wall.holder = {
		has_government = nights_watch_government
		has_title = title:$TITLE$
		NOT = { any_court_position_holder = { type = $KEEPER$ } }
	}
}

# Is ANY of the eighteen open? Gates the decision, so the effect below can never run off the end of the

# Could this man take the black at all? Mirrors AGOT's own valid_character on every keeper -- male, adult, not
# a maester or a septon, not already sworn, not the landless First Ranger -- so the decision never offers a
# door that appoint_court_position would then refuse at the threshold.
# ══ SENDING THE DUNGEONS TO THE WALL (1.0.16a) ═══════════════════════════════════════════════════════════
# Thomas: "I honestly never know who I can send to the Night's Watch."
#
# HE IS NOT MISSING SOMETHING. AGOT puts every eligibility condition for its Send to the Wall option in
# `is_shown` (00_prison_interactions.txt:6129-6162), and an is_shown failure REMOVES THE OPTION ENTIRELY --
# no greyed button, no tooltip, nothing. The one tooltip that does exist says only "Send to Night's Watch",
# and one of the two conditions that DO render, `release_banish_invalid_send_to_nw`, has no localisation
# anywhere in AGOT, vanilla or here, so it prints as a raw key. The most common blocker of all is invisible:
# a LANDED enemy lord can never be sent, only your vassals-or-below and your own courtiers.
#
# So these two triggers exist to be READ OUT LOUD, not to gate. They mirror agot_nw_can_banish
# (00_agot_nights_watch_triggers.txt:23-50) clause for clause, split into the two halves a player actually
# needs told apart: what is wrong with YOU, and what is wrong with HIM.
#
# WHY MIRROR RATHER THAN WRAP -- and this is a deliberate exception to the do-not-reinvent rule, not an
# oversight. agot_nw_can_banish is parameterised on TWO scopes ($BANISHER$/$BANISHEE$) and every caller
# passes saved scopes; there is no saved scope for "the prisoner currently being tested" inside an
# every_prisoner limit. And a single bundled trigger cannot say WHICH clause failed, which is the entire
# feature. So: the mirror below explains, and AGOT's own trigger is still called as the FINAL AUTHORITY in
# the decision's effect before anybody is actually sent. We can therefore never send a man AGOT would not.
# If AGOT changes agot_nw_can_banish, the sending stays correct and only the explanation goes stale --
# which is the safe direction to drift in. Re-check this against their file after an AGOT update.

# Root = the man in your dungeon. The BANISHEE half.
ln_prisoner_fit_for_the_wall_trigger = {
	is_alive = yes
	is_ai = yes
	is_male = yes                              # AGOT: agot_valid_potential_nw_member. Thomas's ruling stands -- brothers.
	age >= 10                                  # AGOT's number, and note it is not adulthood.
	culture = { agot_is_wildling_culture = no } # a free folk captive will not swear.
	# Ours, not AGOT's: a man already sworn, already dead, or not a man at all.
	NOR = {
		has_trait = nightswatch
		has_trait = nightswatch_temp
		has_trait = nightswatch_historical
		has_trait = wight_trait
		has_trait = other_trait
		has_trait = nightking
		has_trait = dragon
	}
}

# ══ 1.1.0 FEATURE I -- THE §10 REPAIR: WHO IS TOO GREAT FOR THE WALL ════════════════════════════
# ln_prisoner_fit_for_the_wall_trigger above answers "could the Wall take this man at all" -- AGOT's own
# clauses, mirrored so each can be read out loud. It never asks who he IS. Neither does agot_nw_can_banish:
# AGOT keeps its relationship test in send_to_nightswatch_interaction's is_shown trigger_if chain
# (00_prison_interactions.txt:6129-6162) and nowhere else, and agot_nw_can_banish is only the tooltip
# beneath it. 1.0.16a's decision treated the tooltip trigger as final authority, so a captured independent
# king passed every check we made. Thomas, before it was even confirmed: "what if I capture the King of
# Westeros... next thing you know the King of the Iron Throne is now a part of the Night's Watch." He can.
# This is the repair, decided 31 Aug 2026: tier ceiling ON behind a game rule, last-of-house ON.
#
# Root = the character doing the sending. This = the man in the dungeon.
ln_prisoner_not_too_great_for_the_wall_trigger = {
	# No independent rulers -- the King of Westeros case, stated directly.
	custom_description = {
		text = ln_wall_he_is_a_king_in_his_own_right
		NOT = { is_independent_ruler = yes }
	}
	# No house heads. is_house_head is vanilla's scripted trigger (00_dynasty_triggers.txt:3); = no negates.
	custom_description = {
		text = ln_wall_his_house_looks_to_him
		is_house_head = no
	}
	# No dynasts. Vanilla scripted trigger, 00_dynasty_triggers.txt:15.
	custom_description = {
		text = ln_wall_his_dynasty_looks_to_him
		NOT = { is_dynast = yes }
	}
	# Not the last living member of his house. The count INCLUDES the prisoner himself, so >= 2 means
	# somebody else still lives -- no prev-reach, no self-exclusion needed (the §10 trap). Wrapped in
	# trigger_if on exists, NOT house ?=: ?= fails closed and would have silently blocked every LOWBORN
	# prisoner in the mod -- a man with no house cannot end one. Test cases: two-member house passes
	# (the other member survives him), one-member house is refused.
	trigger_if = {
		limit = { exists = house }
		custom_description = {
			text = ln_wall_he_is_the_last_of_his_house
			house = {
				any_house_member = {
					count >= 2
					is_alive = yes
				}
			}
		}
	}
	# The tier ceiling, behind a game rule (standing rule 13). A captured duke becoming a sworn brother is
	# nearly as strange as a king. has_game_rule takes the OPTION name (standing rule 14).
	trigger_if = {
		limit = { NOT = { has_game_rule = ln_wall_send_any_tier } }
		custom_description = {
			text = ln_wall_he_is_too_great_a_lord
			highest_held_title_tier <= tier_county
		}
	}
}

# The full §10 gate for the decision: could the Wall take him, is he yours to send, is he not too great.
# Root = the gaoler taking the decision. This = the prisoner being tested.
ln_prisoner_may_be_sent_to_the_wall_trigger = {
	ln_prisoner_fit_for_the_wall_trigger = yes

	# THE RELATIONSHIP LAYER -- AGOT's three is_shown legs from send_to_nightswatch_interaction
	# (00_prison_interactions.txt:6129-6162), mirrored leg for leg. This is the test 1.0.16a shipped
	# without: only your own vassals-or-below, the servants of your vassals, and your own courtiers.
	trigger_if = {
		limit = { is_playable_character = yes }
		custom_description = {
			text = ln_wall_he_is_not_yours_to_send
			is_vassal_or_below_of = root
		}
	}
	trigger_else_if = {
		limit = {
			exists = employer
			NOT = { employer = root }
		}
		custom_description = {
			text = ln_wall_he_is_not_yours_to_send
			employer = { is_vassal_or_below_of = root }
		}
	}
	trigger_else = {
		custom_description = {
			text = ln_wall_he_is_not_yours_to_send
			is_courtier_of = root
		}
	}

	ln_prisoner_not_too_great_for_the_wall_trigger = yes
}

# ── ln_can_send_prisoners_to_the_wall_trigger WAS REMOVED HERE (31 Aug 2026). It no longer exists. ────
#
# It bundled the three BANISHER-side conditions -- not of the free folk, seat inside the Seven Kingdoms,
# a Watch still standing -- into one call. `wirecheck2` caught it defined and never called: the decision
# was built the other way round, and deliberately.
#
# WHY THE BUNDLE COULD NOT BE USED. The whole point of this feature is that AGOT tells a player NOTHING
# when he cannot send a man -- every condition sits in `is_shown`, and an `is_shown` failure deletes the
# option instead of greying it. So our decision spends three separate `custom_description` blocks, one
# per condition, in `is_valid` -- see zz_ln_nights_watch_decisions.txt:51-66. A bundled trigger returns
# one boolean and cannot say WHICH clause failed, which is exactly the thing we are fixing.
#
# WHERE EACH CLAUSE WENT, verified line by line before this was removed:
#   culture = { agot_is_wildling_culture = no }                    -> decisions:54-57  ln_wall_you_are_of_the_free_folk
#   primary_title ?= { ... world_westeros_seven_kingdoms }         -> decisions:58-65  ln_wall_your_seat_is_not_in_the_seven_kingdoms
#   ln_a_watch_still_stands_trigger = yes                          -> decisions:66-69  ln_wall_there_is_no_watch_left
#
# Nothing is lost and nothing else called it. Do not re-add it: a future caller that wants all three at
# once should call the three, so the reason survives to the tooltip.

# Split out because the decision names it separately and because it is the one that changes during a game.
ln_a_watch_still_stands_trigger = {
	OR = {
		title:k_the_wall.holder ?= { government_has_flag = government_is_nw }
		title:d_the_wall.holder ?= { government_has_flag = government_is_nw }
	}
}

ln_can_take_the_black_trigger = {
	is_male = yes
	is_adult = yes
	is_alive = yes

	# ── 1.0.17: THE FREE FOLK DO NOT TAKE THE BLACK, AND NEITHER DOES A MAN STANDING IN ESSOS ───────────
	# Thomas, live: "a wildling can do the decision Take the Black -- that should only be available to
	# people within the iron throne's domain, adventurer or landed."
	#
	# NEITHER CLAUSE IS AN INVENTION; BOTH ARE AGOT'S OWN RULE. agot_nw_can_banish
	# (00_agot_nights_watch_triggers.txt:23-39) opens with their comment -- "Must be not a wildling and
	# have a capital in westeros to send" -- and applies culture = { agot_is_wildling_culture = no } to
	# BOTH the banisher and the banishee. And ln_prisoner_fit_for_the_wall_trigger, FORTY LINES ABOVE
	# THIS ONE IN THIS FILE, already carries the culture line with the reason on it: "a free folk captive
	# will not swear."
	#
	# This was the only door into the Watch in the mod that lacked it. The other three were checked:
	# ln_man_an_empty_castle_decision and ln_take_the_black_and_wait_decision are brother-only
	# (ln_is_an_unplaced_brother_trigger requires ln_is_a_sworn_brother_trigger), and
	# ln_send_the_dungeons_to_the_wall_decision carries the gate on both sides already. One door, missed.
	culture = { agot_is_wildling_culture = no }

	# WHERE HE STANDS, NOT WHAT HE HOLDS. AGOT tests the banisher's primary_title capital, which is right
	# for a lord sending somebody else and wrong here: this decision deliberately admits the landless --
	# "the poorest start in the mod is also the most authentic one," and is_landed = no is an explicit
	# branch of its is_valid -- and an adventurer has no primary title to test.
	#
	# location is the equivalent that survives him: 587 uses across vanilla and AGOT, and AGOT tests
	# characters exactly this way in 00_agot_cultural_triggers.txt:17. world_westeros_seven_kingdoms
	# CONTAINS world_westeros_the_wall (00_agot_geographical_region.txt), so a man already standing at
	# Castle Black passes, and it excludes world_westeros_beyond_the_wall and the whole of Essos. It is
	# map data, not politics, so it does not move when the North falls to the dead.
	#
	# ?= rather than =: a character with no location fails closed and the decision simply does not show,
	# which is the right answer for a man who is nowhere -- and it cannot throw the "Character with no
	# location in link 'location'" that vanilla's own health_events does.
	location ?= { geographical_region = world_westeros_seven_kingdoms }

	NOR = {
		has_trait = nightswatch
		has_trait = nightswatch_temp
		has_trait = nightswatch_historical
		has_trait = maester
		has_trait = septon
		has_trait = wight_trait
		has_trait = other_trait
		has_trait = nightking
		has_government = nights_watch_government
	}
	# AGOT's own valid_character excludes the landless First Ranger from every keepership, so a man holding
	# that title must not be offered this decision either. Guarded on existence because this runs in is_shown
	# -- AGOT can compare against an empty title holder inside valid_character, which is evaluated once on a
	# candidate list; is_shown is evaluated constantly.
	trigger_if = {
		limit = { exists = title:d_nw_landless_first_ranger.holder }
		NOT = { this = title:d_nw_landless_first_ranger.holder }
	}
}

# ── IS THIS MAN WORTH A CASTLE? ─────────────────────────────────────────────────────────────────────────────
# Thomas, looking at the decision in game: "I feel like some of that description needs to have, like, a reason.
# Why am I able to man an empty castle? I'm basically a nobody."
#
# THE WATCH TAKES ANYONE. That is not negotiable -- it is the entire character of the institution, and AGOT's
# own joining routes stay open to every man in Westeros regardless of what this trigger says. What this gates
# is being handed one of nineteen CASTLES on arrival, which is a completely different proposition.
#
# Four doors, any one of which is enough, because four different kinds of man should be able to walk through:
#
#   A NAME -- 500 prestige. A hedge knight with a reputation, a tourney winner, a second son who has been
#   somewhere. Not a great lord; a man the Lord Commander has heard of.
#
#   A SEAT TO LAY DOWN -- any landed ruler at any tier. A lord who gives up a county to take the black is the
#   most valuable recruit the Watch has ever had and no commander alive would put him in the kitchens.
#
#   A SWORD PEOPLE KNOW -- an anointed knight. The Watch has always taken knights gladly and given them
#   command, because a knight arrives already knowing how to hold a wall.
#
#   MEN AT HIS BACK -- an adventurer with a real company. The Watch has nineteen castles and no men; a man who
#   turns up with his own is solving the exact problem.
#
# is_knight and max_military_strength both checked against the base game first (75 and 78 uses). The obvious
# `any_army = { army_size >= N }` was the first thing I wrote and it has ZERO uses in the entire base game --
# it would have been a silent no-op.
ln_worth_a_castle_trigger = {
	OR = {
		prestige >= 500
		is_landed = yes
		is_knight = yes
		max_military_strength >= 200
	}
}

# Did the handover actually land? Used by ln_watch.9, whose options have to differ depending on whether a
# castle came free in the week the rider was away -- a revoke can be refused, and the man can die on the road.
ln_carries_a_keepership_trigger = {
	is_landed = yes
	has_government = nights_watch_government
}

# ── ALREADY SWORN, AND NOT YET GIVEN ANYTHING ───────────────────────────────────────────────────────────────
# THOMAS RESTRUCTURED THIS AND HE WAS RIGHT: "That decision should be locked behind somebody who is already a
# Night's Watch, because the other decision, Take the Black, should kinda be your way into the Night's Watch.
# I shouldn't just be able to get a castle with the Night's Watch."
#
# So there is now ONE ENTRANCE and TWO PROMOTIONS, and the entrance is the only thing an outsider can see:
#
#   Take the Black          -- anyone. You come out the other side a ranger with a camp.
#   Man an Empty Castle     -- a sworn brother who holds nothing, when a castle stands empty.
#   Ask for a Castle        -- a ranger trading his company for a roof.
#   Ask for a Command       -- either of the above, when nothing stands empty and somebody must be relieved.
#
# The old shape let a stranger walk up to the Wall and be handed a county the same afternoon, which is exactly
# what Thomas kept flagging from two different directions.
ln_is_a_sworn_brother_trigger = {
	is_alive = yes
	is_adult = yes
	OR = {
		has_trait = nightswatch
		has_trait = nightswatch_temp
		has_trait = nightswatch_historical
	}
	exists = title:k_the_wall.holder
	OR = {
		this = title:k_the_wall.holder
		any_liege_or_above = { has_title = title:k_the_wall }
	}
}

# A sworn brother who holds no castle and no ranging company -- the man in the Lord Commander's hall waiting
# to be given something. This is who Man an Empty Castle is for.
ln_is_an_unplaced_brother_trigger = {
	ln_is_a_sworn_brother_trigger = yes
	is_landed = no
	NOT = { has_government = ln_ranger_government }
	NOT = { this = title:k_the_wall.holder }
}

# 1.0.12a -- DID THE WATCH SURVIVE THE LONG NIGHT? Daysniper, Discord: "I managed to stop the Others before
# they destroyed the Wall as the Night's Watch. But I got the event for the Free Folk coming south and that
# the Watch is gone." He is right and the card was lying to him -- ln_aftermath.1 assumed the Wall always
# falls, because in every playtest it had.
#
# THREE CONDITIONS, and the third is the one that matters. A k_the_wall that exists with a holder is not
# enough: the Others take the title rather than destroying it, so a Wall held by the dead satisfies the first
# two and is the exact case the dilemma IS for.
ln_the_watch_survived_trigger = {
	exists = title:k_the_wall
	exists = title:k_the_wall.holder
	title:k_the_wall.holder = {
		ln_is_one_of_them_trigger = no
		# 1.0.16a -- AND "NOT UNDEAD" IS NOT "IS THE NIGHT'S WATCH".
		# A living wildling who took the Wall passed all three of the old conditions, so the Question of the
		# North told the crown the Watch was still standing and option A then handed six titles to a brand new
		# Lord Commander. RedSaintNino: "my Wildlings took the Wall in my playthrough. Huge moment, point of
		# pride. The mod just gave it back to the night watch... this was no fun."
		# government_is_nw is AGOT's own way of asking this and already this mod's idiom
		# (zz_ln_lord_commander_decisions.txt:50, zz_ln_independence_war_shadow.txt:47). It covers
		# nights_watch_government, AGOT's first_ranger_government and our own ln_ranger_government -- and a
		# conqueror cannot acquire any of them, because nights_watch_government's can_get_government requires
		# an NW trait (00_agot_government_types.txt:189-201).
		government_has_flag = government_is_nw
	}
}


# ── IS THIS WALL TITLE ACTUALLY FREE TO RECLAIM (1.1.0, 1 Sep) ─────────────────────────────────────────────
# WORKSHOP REPORT, RedSaintNino, 28 Aug: "my Wildlings took the wall in my playthrough. Huge moment, point of
# pride. The mod just gave it back to the night watch... this was no fun, but I think you can fix it!"
#
# HE IS RIGHT AND THE CAUSE IS SIX BARE LINES. The Watch-restoration effect
# (agot_long_night_scripted_effects.txt) ends with six `get_title` calls guarded only by
# `holder ?= { is_ai = yes }`. That guard was added in 1.0.16a to stop the effect stealing from the PLAYER --
# and it does that. What it never asked was whether the AI holding the title had WON it. A wildling king who
# took Castle Black by force, a northern lord who garrisoned the Nightfort, a player's own vassal holding
# Eastwatch: all AI, all robbed, silently, by a restoration effect that was written for an EMPTY Wall.
#
# THE RULE THIS ENCODES: the Watch may repopulate a Wall that nobody is holding, or one the dead are holding.
# It may never take a castle off a living realm that conquered it. Undoing a player's conquest is the single
# least fun thing a mod can do, and this did it to the one moment on the Wall worth having.
#
# The four government clauses are CK3's and AGOT's own "nobody really holds this" states -- the same three
# the playable rule refuses to hand a player (zz_ln_playable_rules.txt) plus ruins. A title sitting in one of
# those is unclaimed in every sense that matters.
ln_wall_title_is_reclaimable_trigger = {
	OR = {
		NOT = { exists = $TITLE$.holder }
		$TITLE$.holder ?= { ln_is_one_of_them_trigger = yes }
		$TITLE$.holder ?= { has_government = nights_watch_government }
		$TITLE$.holder ?= { has_government = ruins_government }
		$TITLE$.holder ?= { has_government = unknown_government }
		$TITLE$.holder ?= { has_government = wilderness_government }
	}
}
