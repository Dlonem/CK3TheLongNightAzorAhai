# AGOT: The Long Night & Azor Ahai -- a man's record.
#
# THE PROBLEM THESE SOLVE. CK3 lints every character flag that is SET and never READ as an error at load:
#
#   [E][jomini_effect.cpp:1161]: Variable 'ln_chosen_refused_a_king' is set but is never used.
#                                Note that use in localization doesn't count due to technical limitations
#
# Seventy-two of those from this mod in Thomas's 108 AC log. Every one is an option a player took -- went north
# or stayed south, hunted the shadowcat or bought the lion, kept the lie or broke it -- recorded so the ending
# could reflect it, and then read nowhere, because the reading was always going to be in localization and the
# engine says outright that localization does not count.
#
# So the record is now genuinely read: grouped by chain here, consumed by the chronicle (ln_reveal.9) to decide
# what kind of man the histories are writing about. That clears the lint by making the claim true rather than
# by deleting the record, and the ending is better for it.
#
# GENERATED by /tmp/flags.py from every add_character_flag in the mod, so a flag added tomorrow is picked up by
# re-running it rather than quietly rejoining the lint. The generator excludes THIS file when it scans for
# reads -- the first version did not, decided nothing was unread any more, and emptied itself.

	}
}
