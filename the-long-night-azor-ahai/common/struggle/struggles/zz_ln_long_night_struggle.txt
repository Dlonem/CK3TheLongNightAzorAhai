# AGOT: The Long Night & Azor Ahai -- the Long Night as a struggle.
#
# WHY A STRUGGLE. Before this, the Long Night was binary: not here, then here. There was no way for a player to
# look at the world and know how close the dark was, and nothing they built read as preparation or as negligence.
# A struggle gives the whole campaign a visible spine.
#
# WHY IT LOOPS. AGOT's own btw_struggle carries a commented-out stub -- "# struggle_btw_phase_others = { # TODO:
# White Walker invasion" -- so this is finishing something they started. Vanilla's Iberian struggle is confirmed to
# ship with NO ending phase: four phases that cycle, ended only by decision. We do the same, because the recurrence
# game rule needs the cycle to be able to turn. Under "Once" the Dawn calls end_struggle and it concludes; under
# "The Cycle" it flows back to the Long Summer and ln_wave_count ticks over. One clock, not two.
#
# PACING IS SCRIPT-DRIVEN. Every catalyst here is ours and fired from our own code, so the game rule tunes how
# fast points accrue rather than editing thresholds. The Long Summer's 100 points against a 1-point yearly drip is
# roughly a century, with events pulling it in.
#
# NOTE: phase-level `background` is NOT a valid field -- error.log rejects it as an unexpected
# token. The only occurrence in AGOT is inside a commented-out block, which should have been
# the clue. The struggle-level `illustration` above is what actually renders.
#
# WHERE THE PHASE HOOKS ARE. Not here. CK3's own schema (game/common/struggle/struggles/_struggles.info) gives a
# phase-level `on_start` to the ENDING phase only; ordinary phases have no such field, and neither vanilla struggle
# uses one. Phase-entry work is latched in ln_struggle_monthly_effect off the struggle-level on_monthly instead,
# which is correct no matter how a phase was entered. See zz_ln_struggle_effects.txt for the reasoning in full.
#
# WHERE THE MECHANICAL EFFECTS COME FROM. The *_parameters blocks below are NOT engine magic -- confirmed by
# grepping vanilla: every parameter it ships (holy_order_can_be_created_by_dukes, unlocks_border_raid_casus_belli,
# invasion_conquest_war_cannot_be_declared, ...) is read back by ordinary script via has_struggle_phase_parameter.
# A parameter nobody reads does nothing but print a line in the tooltip. So everything here that must actually
# BITE is a *_character_modifier or a *_county_modifier, which the engine applies on its own; the parameters are
# the readable summary plus the hooks our own code branches on.
#
# INVOLVED vs INTERLOPER vs UNINVOLVED, in this mod's terms:
#   involved   = the people who already live under the cold -- the North, the free folk, the clans beyond the Wall
#   interloper = the southern realms inside the region who will find out
#   uninvolved = Essos and everyone else, who will read about it and sell to the survivors
