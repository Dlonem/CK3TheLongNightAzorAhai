# AGOT: The Long Night & Azor Ahai -- THE KILLING BLOW.
#
# ══════════════════════════════════════════════════════════════════════════════════════════════════════════════
# WHY THIS IS ON on_combat_end_winner AND NOT IN A COMBAT PHASE EVENT.
#
# The store page promises "killing the Night King as a full scene", and design-backlog.md §1 proposed getting it
# by overriding vanilla's `knight_killed` with an is_valid gate, citing Princes of Darkness as precedent.
# common/combat_phase_events/zz_ln_knight_phase_events.txt already contains the research that KILLED that plan,
# and it still holds: AGOT's knight_killed is 993 lines against vanilla's 463, with 587 lines of differences
# including their own `is_valid = { is_current_dragonrider_warfare = no }`. Shipping our copy silently reverts
# every one of those the day AGOT edits it -- dragonriders quietly become knight-killable again, and nothing
# logs it.
#
# THIS IS THE THIRD ROUTE, and it needs no file of theirs and no file of vanilla's. AGOT itself hangs
# agot_others_events.9000 and agot_combat_event.1000 off on_combat_end_winner, which gave us the scope shape for
# free: root is the WINNING combat_side, with side_commander, enemy_side and combat.location all reachable.
# So: you beat his army in the field, and then the scene happens.
#
# WHAT IT DOES NOT DO. It does not intercept his death, because nothing in CK3 can -- on_death is reactive and
# on_natural_death_second_chance is natural-death only, both verified previously. It does not need to. He is
# alive when this fires; whether he stays that way is the point of the card.
# ══════════════════════════════════════════════════════════════════════════════════════════════════════════════

# ── 1. THE DIRECTOR ─────────────────────────────────────────────────────────────────────────────────────────
# Root = the winning combat_side. Hidden, rootless-by-character, fires the scene at the man who won.
ln_dawn.1 = {
	hidden = yes
	scope = combat_side

	trigger = {
		# Somebody human won it, and lived to stand in the field afterwards.
		exists = side_commander
		# 1.0.16 -- `is_ai = no` REMOVED FROM HERE. It made the mod's flagship scene player-only, so
		# JON SNOW COULD NEVER FIGHT THE NIGHT KING. No AI champion could, in any run, ever. Thomas:
		# "wouldn't that opportunity for allowing an AI to try and end the Long Night, aka say Jon Snow
		# defeats the Night King in battle, is he going to be able to have that duel occur? Because that's
		# ideal." A world where only the player can end it is a world where nothing happens without you.
		# Every option in ln_dawn.2 now carries an explicit ai_chance so the AI's choice is designed rather
		# than inherited, and ln_dawn.4's re-arm now protects the player's own shot -- see the notes there.
		side_commander = {
			is_alive = yes
		}

		# ══ 1.0.16a -- HE MUST BE ON THE FIELD, NOT MERELY THE OWNER OF THE WAR. ════════════════════════════
		# RedSaintNino: "I killed a micro army of the night king, a 2000 man force, and it tigered [triggered]
		# the end of the night king." side_primary_participant on a combat side is the character the SIDE
		# BELONGS TO -- so every skirmish any of his stacks lost matched this, and the first one to do it spent
		# the one-shot ln_dawn_offered latch below. A scouring party losing a scrap in the Riverlands could
		# consume the mod's flagship scene, and under others_death_resolution the duel that follows ends the
		# whole Long Night.
		#
		# any_side_commander / any_side_knight are vanilla's own combat_side iterators
		# (game/events/war_events/combat_events.txt:2077-2080; already used in this mod at
		# zz_ln_spear_triggers.txt:57-62). They cover a side holding several armies, so a stand-in still cannot
		# hide him -- he simply has to have been there. NO is_ai CLAUSE: 1.0.16 deliberately removed that so an
		# AI champion can end it, and that stays.
		#
		# THE OLD COMMENT HERE WAS WRONG and is not carried over: it claimed the story cycle re-assigns him as
		# army commander every fifteen days. Nothing in common/story_cycles/the_long_night.txt assigns a
		# commander at all. The mod's only assign_commander is 00_others_heartbeat_events.txt:175-187 and it
		# fires ONLY for armies already besieging. In a field battle his commandership is CK3's AI's choice --
		# which is why the knight arm below is load-bearing, not belt-and-braces.
		exists = enemy_side
		enemy_side = {
			OR = {
				any_side_commander = { has_trait = nightking }
				any_side_knight = { has_trait = nightking }
			}
		}

		# Once. The wheel can turn under The Cycle, so this is cleared with the other latches at a new summer
		# rather than being permanent.
		NOT = { has_global_variable = ln_dawn_offered }
	}

	immediate = {
		set_global_variable = { name = ln_dawn_offered  value = yes }

		# 1.0.16 -- THE LATCH IS SET HERE AND THE CARD LANDS TOMORROW, AND THAT GAP HAD NO FLOOR UNDER IT.
		# ln_dawn.2 is queued below with days = 1 and carries a real trigger of its own. If the winning
		# commander dies inside that day -- a wound, a murder, the next battle -- the card is dropped and
		# NOTHING re-arms: ln_dawn_offered is a global, it is cleared only at a new summer under The Cycle,
		# and ln_dawn.1's own trigger refuses to run again while it stands. One unlucky night and the mod's
		# flagship scene is gone for the rest of the wave, silently, with no error in the log to say so.
		#
		# The latch is NOT simply moved into ln_dawn.2's immediate, which was the obvious fix and is the
		# wrong one: for that whole day the latch would be down, and every other victorious commander
		# against the Night King's host would fire ln_dawn.1 too. Several ln_dawn.2s, one scene.
		#
		# So: pending marker here, cleared by ln_dawn.2 when it actually lands, and a watchdog three days
		# out that re-arms if it never did. The watchdog rides the NIGHT KING, deliberately -- he is the one
		# character this chain guarantees is alive (ln_dawn.1's own trigger requires it), and if he dies
		# before it fires then the Long Night has ended by some other road and the latch no longer matters.
		# Re-arming by removing ln_dawn_offered is this file's established idiom, not a new mechanism: see
		# ln_dawn.2's option b at :433 and ln_dawn.4 at :543.
		set_global_variable = { name = ln_dawn_scene_pending  value = yes }
		debug_log = "LN_TRACE DAWN: the killing-blow director fired - the field scene is armed and queued for tomorrow"

		# 1.0.16a -- AND THE SCOPE MUST FOLLOW THE TRIGGER. The trigger above now admits him as a KNIGHT as
		# well as a commander; the old `else` here grabbed side_primary_participant, which is the side's owner
		# and need not be him. Every branch below now saves the man the trigger actually matched.
		enemy_side = {
			if = {
				limit = { any_side_commander = { has_trait = nightking } }
				random_side_commander = {
					limit = { has_trait = nightking }
					save_scope_as = ln_night_king
				}
			}
			else = {
				random_side_knight = {
					limit = { has_trait = nightking }
					save_scope_as = ln_night_king
				}
			}
		}

		# ── 1.1.0a: days = 1 -> 2, SO THE SPEAR CARD IS ALWAYS READ FIRST. ──────────────────────────────
		# Thomas's 3 Sep run: ln_spear.1 ("Out of the Sky") and ln_dawn.2 ("The Field Afterwards") arrived
		# together off the same battle, and the second one contradicted the first. Both hang off
		# on_combat_end_winner and both were scheduled `days = 1`, so they landed on the same day; his
		# ln_dawn.2 debug panel shows ln_dawn_dragon still saved as Paarthurnax -- the dragon the Night King
		# had just taken out of the sky one card earlier -- and the card he read was the dragon variant,
		# "the thing above you, the heat coming off it in waves".
		#
		# ORDERING IT HERE RATHER THAN IN THE HOOK. zz_ln_00_hooks.txt:226 runs ln_dawn_combat BEFORE
		# ln_others_spear, so this hook cannot see a flag the spear has not set yet, and reordering the
		# sub-list would move which saved scopes exist when -- a much larger change than the bug.
		# One day is enough: ln_spear.1's immediate is what clears the rider's dragon, so by day 2
		# ln_dragon_is_over_the_field_trigger correctly reads no and the desc chain falls through to
		# ln_dawn.2.desc.spear, which was written for exactly this man and until now could not be reached
		# on the same battle that earned it.
		#
		# ln_dawn.5's day 3 is untouched and still lands after this; ln_dawn.12's failsafe is +14/16 days.
		side_commander = { trigger_event = { id = ln_dawn.2  days = 2 } }
		scope:ln_night_king = { trigger_event = { id = ln_dawn.5  days = 3 } }
	}
}

# ── 5. THE WATCHDOG ON THE FIELD SCENE ──────────────────────────────────────────────────────────────────────
# 1.0.16. Root = the Night King. Hidden, no options, no localization -- it exists only to notice that
# ln_dawn.2 never landed and to give the wave its scene back. See the note in ln_dawn.1's immediate for why
# it rides him rather than the commander, and why the latch was not simply moved.
# Costs one queued event per wave and does nothing at all in the normal case, where ln_dawn.2 landed on day
# one and cleared the marker two days before this fires.
ln_dawn.5 = {
	type = character_event
	hidden = yes

	trigger = {
		has_global_variable = ln_dawn_scene_pending
		has_global_variable = ln_dawn_offered
	}

	immediate = {
		debug_log = "LN_TRACE DAWN: the field scene never reached its commander - re-arming ln_dawn_offered"
		remove_global_variable = ln_dawn_scene_pending
		remove_global_variable = ln_dawn_offered
	}
}

# ── 2. THE FIELD AFTERWARDS ─────────────────────────────────────────────────────────────────────────────────
# Root = the winning commander. scope:ln_night_king survives from the director; scopes do cross trigger_event.
ln_dawn.2 = {
	type = character_event
	title = ln_dawn.2.t
	desc = {
		first_valid = {
			# ── 1.0.15c REVIEW FIND: THIS BRANCH GOES FIRST, ABOVE EVERY ARMAMENT LINE. ──────────────
			# The bane rule made the winning branch unreachable without obsidian, Valyrian steel or a
			# dragon -- and the card that explains that ("a good sword that will do nothing at all") was
			# the LAST entry in this chain, so four earlier descs shadowed it. Worse, the two the rule
			# itself produces -- ln_faced_him_and_lived, set by both ln_dawn.4 and ln_dawn.11.c -- route
			# a man straight to desc.again, so the exact population created by the rule never read it.
			# A man holding nothing is told he is holding nothing, before anything else is said.
			triggered_desc = {
				trigger = { ln_bears_the_bane_trigger = no }
				desc = ln_dawn.2.desc.nothing
			}
			# What you are holding, most decisive first. This is the whole "tier the killing blow by what you
			# brought" idea from design-backlog.md, and the card says it out loud so the choice is informed.
			# 1.0.13 -- DAWN IS NOT A FORGED SWORD AND SHOULD NOT BE DESCRIBED AS ONE. Both consecration
			# routes set ln_forged_lightbringer (zz_ln_consecration_effects.txt:19) so the weighting below
			# already reached them -- but the Dawn route also sets ln_the_star_paid_for_it, which nothing
			# read, and a man carrying the Sword of the Morning deserves to be told so on this card.
			triggered_desc = {
				trigger = { has_character_flag = ln_the_star_paid_for_it }
				desc = ln_dawn.2.desc.dawn
			}
			triggered_desc = {
				trigger = { has_character_flag = ln_forged_lightbringer }
				desc = ln_dawn.2.desc.lightbringer
			}
			# ⚠ 1 Sep PLAYTEST FIX -- THE WALL. This fired on ln_rides_a_living_dragon_trigger alone, so a
			# rider who cornered him on the Desolate Field was told his dragon was overhead "turning the
			# frost to fog for a hundred yards in every direction" -- on the wrong side of the one ward in
			# the world she will not cross. The card contradicted the mod's own best piece of book lore.
			triggered_desc = {
				trigger = { ln_dragon_is_over_the_field_trigger = yes }
				desc = ln_dawn.2.desc.dragon
			}
			triggered_desc = {
				trigger = { ln_has_deed_valyrian_steel_trigger = yes }
				desc = ln_dawn.2.desc.valyrian
			}
			triggered_desc = {
				trigger = {
					OR = {
						has_character_modifier = ln_dragonglass_armed_modifier
						has_character_modifier = ln_dragonglass_stores_modifier
						has_character_flag = ln_mined_the_glass
					}
				}
				desc = ln_dawn.2.desc.glass
			}
			triggered_desc = {
				trigger = { ln_is_a_champion_of_rhllor_trigger = yes }
				desc = ln_dawn.2.desc.named
			}
			# The other half of the Wall rule. You have a dragon; she is a hundred leagues south of here
			# because she would not come. Deliberately the LAST armament branch: a rider who ALSO carries
			# Valyrian steel or obsidian is told about the thing that is actually in his hand, because that
			# is the thing that can hurt him. This branch only catches the man whose dragon was the plan.
			triggered_desc = {
				trigger = {
					ln_rides_a_living_dragon_trigger = yes
					ln_dragon_is_over_the_field_trigger = no
				}
				desc = ln_dawn.2.desc.dragon_refused
			}
			# -- AND WHETHER YOU HAVE BEEN HERE BEFORE ------------------------------------------------
			# Deliberately UNDER every armament branch: a man holding Lightbringer should be told about
			# Lightbringer, not about his memoirs. These catch the man holding nothing -- who until today
			# got the same generic card however many times the thing had already looked at him, because
			# ln_faced_him_and_lived and ln_turned_away_from_him were both set and read by nothing.
			# 1.0.13 -- HE TOOK SOMETHING OF YOURS. Above the two memory branches because it is the more
			# specific memory: a man who merely stood in front of him once, and a man whose dragon is
			# currently flying for the other side, are not carrying the same thing into this.
			# ln_survived_the_spear was set by ln_spear.1 and read by nothing until now.
			triggered_desc = {
				trigger = { has_character_flag = ln_survived_the_spear  exists = scope:ln_spear_dragon }
				desc = ln_dawn.2.desc.spear
			}
			triggered_desc = {
				trigger = { has_character_flag = ln_survived_the_spear }
				desc = ln_dawn.2.desc.spear_unnamed
			}
			triggered_desc = {
				trigger = { has_character_flag = ln_faced_him_and_lived }
				desc = ln_dawn.2.desc.again
			}
			triggered_desc = {
				trigger = { has_character_flag = ln_turned_away_from_him }
				desc = ln_dawn.2.desc.twice
			}
			desc = ln_dawn.2.desc.nothing
		}
	}
	theme = murder_scheme
	override_background = { reference = agot_frozen_forest }
	left_portrait = { character = root  animation = personality_bold }
	# ⚠ ANIMATION: personality_callous, NOT disbelief. 1 Sep playtest, Thomas: "maybe you don't have the
	# Night King showing panic. He's supposed to be in a way emotionless, and he's supposed to be looking
	# at you sternly as if a human could do all of this." disbelief plays as a man who cannot believe what
	# he is seeing -- a human reaction, and the one thing this character has never had. personality_callous
	# is the cold, unmoved stance (verified present in game/gfx/portraits/portrait_animations/animations.txt).
	right_portrait = { trigger = { exists = scope:ln_night_king }   character = scope:ln_night_king  animation = personality_callous }

	trigger = {
		is_alive = yes
		exists = scope:ln_night_king
		scope:ln_night_king = { is_alive = yes }
	}

	immediate = {
		play_music_cue = "mood_the_others"
		# 1.0.16 -- THE CARD LANDED, so the ln_dawn.5 watchdog has nothing to do. Clearing the marker here
		# rather than in an option is deliberate: reaching the card at all is what the watchdog is checking
		# for. Whatever the player then chooses, including walking away, is a choice that was offered --
		# and option b already has its own re-arm for the AI case (:433).
		if = {
			limit = { has_global_variable = ln_dawn_scene_pending }
			remove_global_variable = ln_dawn_scene_pending
		}
		# 1 Sep -- THE REFUSED-DRAGON CARD NEEDS THE ANIMAL BY NAME. ln_dawn.2.desc.dragon_refused was
		# written with "she", and AGOT's dragons are not all female -- Thomas: "not all dragons are girls,
		# and if you're going to reference the sex you need to make sure there's cases for that." The scope
		# lets the text use the name and the engine's own pronoun tokens instead of guessing. Guarded with
		# ?= because most men who read this card have no dragon at all and the branch simply will not run.
		var:current_dragon ?= { save_scope_as = ln_dawn_dragon }
		# 1.1.0 (B6): the spear survivor's card names the dragon the dead took from him. Banked on him in
		# ln_spear.1.a; absent on saves from before 1.1.0, which is why desc.spear is gated on the scope and
		# desc.spear_unnamed exists.
		var:ln_dragon_taken_from_me ?= { save_scope_as = ln_spear_dragon }
	}

	# ── END IT. The roll is the tiering: what you brought is the whole of your chance.
	option = {
		name = ln_dawn.2.a
		# THE BANE GATE MOVED UP HERE when the random_list became a duel. It used to sit on the winning
		# entry of the list; a duel's outcome blocks take weights, not triggers, and faking it with
		# `factor = 0` would fight the `min` floor below. Option-level is also the better read: the man
		# who cannot hurt it does not get offered the swing, he gets ln_dawn.2.d.
		trigger = { ln_bears_the_bane_trigger = yes }
		# 1.1.0 (§7): THE door -- every unarmed player sees what forty years of preparation would have bought.
		show_as_unavailable = { always = yes }
		# ══ 1.0.15 -- A REAL DUEL, ON THE ENGINE'S OWN DUELLING MECHANIC. ══════════════════════════════════
		# Thomas asked the right question: "did you build that Night King duel? Was it mirrored off vanilla
		# duelling? Can somebody with an inferior prowess possibly gain the upper hand? Is it all prowess
		# based? Is it destiny based?"
		#
		# It was NOT, and this is the fix. Until now this was a bare random_list -- a 10-vs-40 coin flip with
		# flat adds, in which prowess was a single +10 above 15 and nothing else. CK3 has a real duel effect
		# (game/events/activities/feast_activity/feast_events_ewan.txt:385 is the clean vanilla example) and
		# this now uses it, so the fight is an actual skill contest between two named men.
		#
		# HOW IT ANSWERS HIS THREE QUESTIONS:
		#   * "Is it all prowess based?" No. `skill = prowess  target = scope:ln_night_king` makes prowess
		#     the contest, and `compare_modifier` turns the MARGIN between the two men into weight -- so a
		#     better swordsman is genuinely better, on a curve rather than a threshold.
		#   * "Can somebody with inferior prowess gain the upper hand?" Yes, and `min = 8` is where that
		#     lives: the success branch can never be weighted below 8 no matter how badly outclassed the
		#     man is. The King of Winter has never lost a fight; that is exactly the fight the songs are
		#     about. `min = -49` on the compare clamps the other direction so the margin cannot erase it.
		#   * "Isn't that where you could write in that destiny system?" It is, and it is now the largest
		#     term on the board. Everything below the compare is the destiny layer -- what you carry, what
		#     you have been named, what the field has already taken out of you, and whether the world is
		#     still looking at somebody else.
		#
		# THE BANE RULE STILL GOVERNS. This option is gated on ln_bears_the_bane_trigger above; the duel
		# decides whether an ARMED man wins, never whether an unarmed one can.
		duel = {
			skill = prowess
			target = scope:ln_night_king

			# ── HE FALLS ────────────────────────────────────────────────────────────────────────────
			10 = {
				desc = ln_dawn.2.duel.win
				compare_modifier = {
					value = scope:duel_value
					multiplier = 2.5
					min = -49
				}
				min = 8

				# WHAT IS IN YOUR HAND. Lightbringer is the prophecy's own answer and is weighted as such.
				modifier = { add = 60  has_character_flag = ln_forged_lightbringer }
				modifier = { add = 55  has_character_flag = ln_the_star_paid_for_it }
				modifier = { add = 35  ln_has_deed_valyrian_steel_trigger = yes }
				# THOMAS'S CORRECTION, 25 Aug: "in a duel, having a dragon isn't relevant." He is right and
				# the +30 that used to sit here was incoherent -- owning a dragon does not make a man better
				# with a sword, and a rider who means to use the animal is not in a duel at all, he is
				# burning the thing from four hundred feet. Dragonfire remains a BANE (it is one of the
				# three things that can end him, ln_bears_the_bane_trigger) so it still buys the rider the
				# right to this scene -- it simply stops pretending to be swordsmanship.
				# THE DRAGON CONFRONTATION WANTS ITS OWN SCENE. Backlogged, not faked here.
				modifier = {
					add = 20
					OR = {
						has_character_modifier = ln_dragonglass_armed_modifier
						has_character_modifier = ln_dragonglass_stores_modifier
						has_character_modifier = ln_dragonglass_knight_modifier
					}
				}

				# WHAT YOU HAVE BEEN NAMED. The spear session's calibration, unchanged: the survival weight
				# is the story refusing to end here, so it belongs to the man the world has named.
				modifier = { add = 30  has_trait = chosen_by_rhllor }
				# AUDIT FIX: the spear table this comment claims to reuse "unchanged" has FOUR rungs, and
				# azor_ahai_reborn was the one dropped. Under The Cycle that made the man who ended the last
				# Long Night weigh LESS here than a merely-Favored one -- while ln_dawn_worthiness_value
				# rates him +40, the largest naming term it has. The funnel picked him and the duel forgot
				# who he was.
				modifier = { add = 25  has_trait = azor_ahai_reborn }
				modifier = { add = 15  has_trait = favored_by_rhllor }
				modifier = { add = 10  has_trait = resurrected_by_rhllor }
				modifier = { add = 10  has_trait = brave }

				# WHAT YOU HAVE ALREADY SURVIVED. Knowledge, not courage -- courage is the line above.
				modifier = { add = 10  has_character_flag = ln_faced_him_and_lived }
				modifier = { add = 10  has_character_flag = ln_survived_the_spear }

				# WHAT THE WAR HAS TAKEN OUT OF YOU.
				modifier = { add = -10  has_trait = wounded_1 }
				modifier = { add = -18  has_trait = wounded_2 }
				modifier = { add = -30  has_trait = wounded_3 }
				modifier = { add = -20  has_trait = maimed }

				# AND WHETHER THE WORLD IS LOOKING AT SOMEBODY ELSE.
				# NOTE FOR ANY FUTURE EDIT: any_living_character is an O(every character alive) scan. It is
				# safe HERE -- it runs once, on one option of one event that fires at most once per wave,
				# and it short-circuits behind the NOT above. It must never be moved onto a pulse: this mod
				# has already shipped and fixed exactly that lag bug once (see the O(1) rewrite note in
				# ln_the_world_forms_a_view_effect, zz_ln_prophecy_effects.txt).
				modifier = {
					add = -10
					NOT = { has_trait = chosen_by_rhllor }
					any_living_character = {
						NOT = { this = root }
						has_trait = chosen_by_rhllor
					}
				}

				trigger_event = { id = ln_dawn.3  days = 1 }
			}

			# ── HE DOES NOT ─────────────────────────────────────────────────────────────────────────
			40 = {
				desc = ln_dawn.2.duel.lose
				compare_modifier = {
					value = scope:duel_value
					multiplier = -2.5
					min = -49
				}
				min = 10

				modifier = { add = -25  has_character_flag = ln_forged_lightbringer }
				modifier = { add = -20  has_character_flag = ln_the_star_paid_for_it }
				modifier = { add = -15  ln_has_deed_valyrian_steel_trigger = yes }
				modifier = { add = -15  has_trait = chosen_by_rhllor }
				modifier = { add = -13  has_trait = azor_ahai_reborn }
				modifier = { add = -8   has_trait = favored_by_rhllor }
				modifier = { add = -10  has_character_flag = ln_faced_him_and_lived }
				# 1.0.16 -- THE GLASS PENALTY. See ln_carries_only_dragonglass_trigger. The three clauses

# `death` routes through on_death -> ln_death_catalyst_effect -> ln_night_king_slain_reveal_effect, which reads

	trigger = {
		exists = scope:ln_night_king
		scope:ln_night_king = { is_alive = yes }
	}

	immediate = {
		play_music_cue = "mood_the_others"
		scope:ln_night_king = {
			# 1.1.0b -- THE STAMP MUST GO ON BEFORE THE BLOW. See ln_mark_the_sanctioned_kill_effect.
			ln_mark_the_sanctioned_kill_effect = yes
			death = {
				death_reason = death_the_dawn
				killer = root
			}
		}

		# ── THE DIAGNOSTIC, and it exists because of how this mod debugs ────────────────────────────────
		# nightking, other_trait and wight_trait are all `immortal = yes` (common/traits/invasions_traits.txt,
		# life_expectancy 12000). CK3's own trait docs say immortal blocks death from NATURAL CAUSES only and
		# explicitly not battle or scripted death, so this should simply work -- but it has never been tested
		# in a live game, and if the engine did refuse it the whole feature would do NOTHING, silently, which
		# is the exact failure this project has lost the most time to.
		#
		# So: if he is somehow still breathing one line later, stamp it. Debug saves are plain text and
		# grep-able, which is how every pacing question in this project has actually been answered -- one
		# search for ln_dawn_death_refused tells us instantly whether the death was refused or the event
		# never fired at all. Costs nothing when everything works, because it never gets set.
		if = {
			limit = { scope:ln_night_king = { is_alive = yes } }
			set_global_variable = { name = ln_dawn_death_refused  value = yes }
		}
	}
